# University Exam Timetabling Optimization

**Birjand University of Medical Sciences (BUMS)**

This project focuses on university-wide examination timetabling using graph coloring and optimization algorithms.

The framework aims to eliminate student examination conflicts, improve examination schedules, and support examination room allocation.

### Study Overview

- University: Birjand University of Medical Sciences
- Academic Programs: 26
- Students: 1,634
- Courses: 299
- Main Approach: Graph Coloring

### Experimental Results

The proposed scheduling approach achieved:

- Zero student examination conflicts.
- Reduction in examination calendar length from 37 to 28 days.
- Improved examination scheduling across the 26 academic programs.

### Main Objectives

1. Construct course conflict graphs.
2. Implement and evaluate graph coloring algorithms.
3. Generate conflict-free examination timetables.
4. Optimize examination room allocation.
5. Compare scheduling algorithms using common benchmarks.

### Technologies

Python | Graph Theory | Combinatorial Optimization | Graph Coloring
